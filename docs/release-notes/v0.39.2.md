# DS1 Multi Randomizer 0.39.2

This public prerelease makes the owner-approved roaming-boss fit rules the default for new worlds while preserving the recorded behavior of existing Seed Code profiles.

- New worlds use `ds1tr-gen-v4`, which includes the updated roaming-boss fit classifications and Pinwheel Chaos candidate handling.
- Existing `ds1tr-gen-v1`, `ds1tr-gen-v2`, and `ds1tr-gen-v3` codes keep their historical roaming-boss behavior. V4 retains the same Compact Fog runtime and data contract as v3.
- Seed Code encoding, settings, and the combined randomizer version salt are unchanged.

This is an unsigned GitHub prerelease for owner QA. Gameplay compatibility has not been claimed from automated generation checks.
