# DS1 Multi Randomizer 0.42.0

**Recommended download: `DS1-Multi-Randomizer-0.42.0-Setup-x64.exe`** (per-user installer, no administrator rights). `DS1-Multi-Randomizer-0.42.0-Portable-x64.exe` is a secondary download: it extracts to a temporary folder every time it starts. Verify files with `SHA256SUMS.txt`, and check where they were built with the GitHub attestation command in the README ("Verify where a release came from"). This release carries GitHub build provenance attestations; an attestation is not a code signature, a virus scan or a safety review.

This release is **unsigned**: no trusted code-signing identity is configured, so Windows SmartScreen or antivirus software may warn. Play offline and back up your saves.

## What changed since 0.41.0

- **New worlds use `ds1tr-gen-v7`, which takes the Fog world from the original FogMod.** Earlier profiles rebuilt the physical Fog map from the game's own map metadata. That rebuild contained routes the game does not have (a jump out of Priscilla's arena into Anor Londo that kills the player, a hallway exit out of the Asylum that does not exist, an arena entered through a wall). Profile V7 uses FogMod's own annotation file unchanged for areas, gates, warps, conditions and key items, runs FogMod's own graph, connector and reachability checker, and writes the game files with FogMod's own writer. Nothing is relaxed to accept more layouts: a layout that cannot be finished is rejected and retried with the next deterministic Fog seed, exactly as before.
- **The Fog game files now match what the original generator writes.** For the same Fog seed the events, talk scripts, parameters and maps written for V7 were compared file by file with the original generator's output (275 files); the only difference is how the archive container is compressed. The areas that were the confirmed trouble spots are covered by regression tests.
- **A complete V7 world has been played through to Gwyn in the game** (owner gameplay QA). Automated checks are still not a claim that every possible world plays correctly.
- **Progression and item placement follow the upstream model.** Every key item and item lot that FogMod declares is read at generation time; the item randomizer only moves items between the places it may, never the route, the key identity or the direction of a gate.
- **Works offline.** V7 needs no download and no earlier run. The one upstream data file it needs is bundled unmodified (its licence was verified); everything else is rebuilt on your computer from your own game files.
- **Run history cleanup.** The history shows the application version and the generation profile of each world and marks older profiles ("Older profile"). "Clear history" (with a confirmation that shows what will go), "Delete from history" for one world, and "Remove old runs" for worlds of older profiles remove the world's own files only. The world that is currently applied is protected, and Restore never depends on a run folder.
- **Seed Codes from earlier versions are unchanged.** Version 1 to 6 codes generate exactly the same worlds as before; they do not switch to the new rules. Old worlds in the history keep working (Apply, Restore).
- **Known limits:** V7 matches FogMod, including the places where FogMod's own model is looser than the game. Some rebuilt talk scripts are checked by comparison rather than by play. Only one full world has been completed in the game.
