# DS1 Multi Randomizer 0.38.4

This public prerelease updates the packaged Electron runtime from 34.5.8 to 44.7.0, a supported stable release. The window keeps its sandbox, context isolation, disabled Node integration, narrow preload API, and navigation guards.

The game-folder picker now supplies its starting folder explicitly and remembers the last visited folder while the dialog is reopened. The selected game path and saved settings remain unchanged.

`electron-updater` 6.8.9 and `electron-builder` 26.15.3 are unchanged. This release is unsigned; verify downloaded files with `SHA256SUMS.txt`. No SignPath status changed.
