**Recommended:**
`DS1-Multi-Randomizer-0.38.2-Setup-x64.exe`

**Portable:**
`DS1-Multi-Randomizer-0.38.2-Portable-x64.exe`

- **Setup** = normal installation for the current Windows user; recommended.
- **Portable** = runs without installation; updates are manual.

## Changes

- GitHub repository ownership references and the built-in update source now use `avoydan/DS1-Multi-Randomizer`.
- README download links point directly to this public prerelease; no stable-only `/releases/latest` URL is used.
- Public builds continue to ignore prereleases. Internal QA builds can still opt in to prerelease updates.

This is an unsigned public pre-release. Windows may show a SmartScreen warning. Back up saves and play offline with modified game data.
