# DS1 Multi Randomizer 0.40.0

Recommended download: **Setup**

- Setup: `DS1-Multi-Randomizer-0.40.0-Setup-x64.exe`
- Portable: `DS1-Multi-Randomizer-0.40.0-Portable-x64.exe`

This public prerelease adds the optional **Free cursor in game menus / Swobodny kursor w menu gry** setting under **Game conveniences / Udogodnienia gry**. It is off by default and saved only in local app settings. When enabled, a small Windows helper releases the cursor clip only while Dark Souls Remastered is the foreground app and the system cursor is visible; it also releases clipping when the game loses focus.

The option does not affect generated worlds, presets, Seed Codes, or randomizer behavior. The helper does not inject into or patch the game, edit saves, or require administrator rights. This release is unsigned; verify downloads with `SHA256SUMS.txt`.
