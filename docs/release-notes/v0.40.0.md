# DS1 Multi Randomizer 0.40.0

**Recommended download: `DS1-Multi-Randomizer-0.40.0-Setup-x64.exe`** (per-user installer, no administrator rights). `DS1-Multi-Randomizer-0.40.0-Portable-x64.exe` is a secondary download: it extracts to a temporary folder every time it starts. Verify files with `SHA256SUMS.txt`.

This is an **unsigned public prerelease for owner QA**. Gameplay of the new Fog behavior has **not** been verified in the game; automated generation checks are not a claim that every world plays correctly. Play offline and back up your saves.

## What changed since 0.39.2

- **New worlds use `ds1tr-gen-v5`.** It carries the corrected Compact Fog V2 topology and a Ceaseless safety rule: after Ceaseless Discharge is defeated, the lower Demon Ruins route must be reachable through the boss's own exit and fixed physical routes, never through another randomized fog gate. Other V5 Fog corrections: Major/Minor PvP fog gates behave correctly when the options are off, Gaping Dragon and Artorias boss fogs keep their intended behavior, and the Capra / Lower Undead Burg landing is placed safely.
- **Known limitation of the conservative Ceaseless rule:** it rejects some Fog layouts that might have been playable. A master seed can therefore run out of its five Fog attempts and ask you to try another seed or change Fog options. In a 1,000-seed study with the Triple defaults, about one in four master seeds produced a world.
- **V1 to V4 Seed Codes are unchanged.** v3 and v4 Seed Codes with Fog enabled work again with the bundled Fog helper (they had been refused with a "cannot reproduce that world exactly" message); the generated worlds are byte-identical to the retired 0.6.0 helper's.
- **Free cursor (F10) helper:** the optional helper no longer starts when the app starts. With the option on, it starts only while Dark Souls Remastered is running (started from the app's Steam button or directly from Steam), at most once per game session, and stops when the game exits or the option is turned off. The option and its shortcut are unchanged and still opt-in. This is not an antivirus or publisher-trust fix.
- **Skill Issue Mode** (default off, local to this computer) adds an overpowered starting loadout for exploration; it does not change the randomized world.

## Trust and verification

- Unsigned: no trusted code-signing identity is configured. Windows SmartScreen or antivirus software may warn. Do not disable protection to run it.
- `SHA256SUMS.txt` and `release-manifest-0.40.0.json` list the exact files and the source commit. A matching hash is not a signature or a safety certification.
- Installed copies only auto-update from non-prerelease GitHub releases, so this prerelease is offered by hand from the release page.
