# DS1 Multi Randomizer 0.41.0

**Recommended download: `DS1-Multi-Randomizer-0.41.0-Setup-x64.exe`** (per-user installer, no administrator rights). `DS1-Multi-Randomizer-0.41.0-Portable-x64.exe` is a secondary download: it extracts to a temporary folder every time it starts. Verify files with `SHA256SUMS.txt`, and check where they were built with the GitHub attestation command in the README ("Verify where a release came from"). This release carries GitHub build provenance attestations; an attestation is not a code signature, a virus scan or a safety review.

This is an **unsigned public prerelease for owner QA**. Gameplay of the Fog behavior has **not** been verified in the game; automated generation checks are not a claim that every world plays correctly. Play offline and back up your saves.

## What changed since 0.40.0

- **New worlds use `ds1tr-gen-v6`, which fixes the root cause of the original Fog hard-lock.** The Asylum starting hallway has exactly one way out, a randomized wall. Earlier generation profiles gave the hallway two unconditional exits that the game does not have, so the solver accepted layouts where that wall led into a dead-end pocket (the confirmed case was the Ceaseless Discharge arena, whose only exit led straight back): the player could walk in and out and nothing else was reachable. The hallway now has no free exit, and after the Fog gates are connected the app checks that every area is reachable from the start. A rejected layout is retried with the next deterministic Fog seed, as before; the number of attempts is unchanged.
- **Two more routes were corrected before release.** The Lost Izalith lava crossing now needs the Orange Charred Ring (both entries; leaving the lava stays free), and the Sen's Fortress cage door needs the Cage Key and no longer connects the middle of the fortress to the roof. Earlier profiles let a layout rely on crossing the lava without the ring or on reaching the roof through the unlocked cage.
- **The Ceaseless-specific post-boss route check of 0.40.0 is retired for new worlds.** It was addressing a different problem, rejected roughly nineteen out of twenty Fog layouts in the project's sample, and only incidentally caught the original loop. In the project's sample of 300 Fog seeds the new rule accepted all of them, against 14 for the old check.
- **Seed Codes from earlier versions are unchanged.** Version 1 to 5 codes (including the 0.40.0 smoke code) generate exactly the same worlds as before; they do not switch to the new rules. Note that an earlier V5 world can still contain the dead-end start described above.
- **Known limits:** only the Asylum start, the lava crossing and the Sen's cage were corrected. A handful of other fixed routes in the project's Fog catalog are unconditional where upstream FogMod has a condition (the project's audit found none that a sampled layout depends on, except the upper Undead Burg residence door in a small share of layouts), and a further set was not cross-checked; any of them could still make a layout optimistic. No world has been played through in the game.

## Trust and verification

- Unsigned: no trusted code-signing identity is configured. Windows SmartScreen or antivirus software may warn. Do not disable protection to run it.
- `SHA256SUMS.txt` and `release-manifest-0.41.0.json` list the exact files and the source commit. A matching hash is not a signature or a safety certification.
- Installed copies only auto-update from non-prerelease GitHub releases, so this prerelease is offered by hand from the release page.
