# DS1 Multi Randomizer 0.38.3

This public prerelease improves update checks after the repository owner change. If GitHub reports no stable release for the confirmed project repository, public builds now show an informational message instead of a connection error. Public builds still ignore prereleases; internal QA builds can still opt in to prerelease updates.

External web content is opened only in the system browser; renderer popups and navigation away from the application are blocked.

This release is unsigned. Verify downloads with `SHA256SUMS.txt` and see the release trust and false-positive reporting guides before reporting a detection.
