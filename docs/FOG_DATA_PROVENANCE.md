# World randomizer data: provenance of the 59 files FogHost reads

FogHost (the Fog engine of DS1 Multi Randomizer, around FogMod `6e6dc7886d0f8bcc53c1800d95c9e859d1f2f87f`) reads exactly
59 files from a "data root" and verifies each of them on every run (`tools/fog-host/src/DataRoot.cs`). Earlier builds made
the player find and select that folder. It is now prepared by the application itself (`apps/backend/src/adapters/worldData.ts`);
this document records where every file comes from and why it is handled the way it is.

## Method

Each file's SHA-256 (text files after CRLF -> LF normalization, as FogHost does) is the one pinned in `DataRoot.cs`. The
files were compared with a clean Dark Souls Remastered installation (Steam build installed 2025-04-12; for event files the
Item Randomizer's untouched `.bak` backups were used, because the live files had been modified by other tools):

- map files (`.msb`) and `GameParam.parambnd.dcx`: byte comparison (SHA-256);
- event files (`.emevd.dcx`): decoded with SoulsFormats and compared event by event (id, instruction bank/id, argument bytes);
- talk scripts (`.talkesdbnd.dcx`): decoded and compared script by script (bytes);
- `Layouts/*.xml` and `fog.txt` do not exist in a Dark Souls installation.

Classes: **A** authored/configuration data from FogMod; **B** layout/schema/metadata; **C** copied or derived Dark Souls
game data (marked *modified* when it differs from the clean installation); **D** unknown origin (no file falls here).

## Result

| Group | Files | Class | Equals the clean installation | Handling |
|---|---|---|---|---|
| `dist/fog.txt` | 1 | A | n/a | fetched once from the upstream repository at the pinned commit |
| `dist/DS1R/Layouts/*.xml` | 4 | B | n/a | fetched once from upstream |
| `dist/DS1R/event/*.emevd.dcx` | 18 | C (modified) | **no**: every file differs (6 events exist only in FogMod's `common`, others are edited) | fetched once from upstream |
| `dist/DS1R/script/talk/*.talkesdbnd.dcx` | 17 | C (modified) | **no**: every archive contains scripts that differ | fetched once from upstream |
| `dist/DS1R/map/MapStudio/*.msb` | 18 | C | **yes**, byte-identical | copied from the verified clean snapshot |
| `dist/DS1R/param/GameParam/GameParam.parambnd.dcx` | 1 | C | **yes**, byte-identical | copied from the verified clean snapshot |

So 19 files are derived from the player's own installation, and 40 cannot be derived because they are not the vanilla
game files: they are the FogMod author's own data (annotations, layouts) and FromSoftware event and talk scripts that the
author edited. A different game build makes the derived hashes fail, which the application reports as an unsupported
version.

## Redistribution decision

On 2026-10-11, the user declined contacting the FogMod maintainer and directed
the project to author an independent equivalent for `fog.txt`. Until that
source exists and passes parity checks, the license scope remains unresolved,
the reference annotation stays development-only, and the production fetch path
is unchanged.

- DS1TR bundles **none** of the 59 files. Event and talk scripts are FromSoftware-derived and are not ours to redistribute.
  `fog.txt` is annotation data stored at `dist/fog.txt`. The repository has an Apache-2.0 license under the sibling
  `FogMod/` directory, but the available evidence does not establish that this license covers `dist/fog.txt`; its
  redistribution status is unresolved. The authorship and license scope for the layout XML files are also not separately
  stated, so they are not bundled.
- The 40 non-derivable files are fetched by the player's own computer, once, over HTTPS, from the FogMod repository itself
  (`https://raw.githubusercontent.com/thefifthmatt/FogMod/<pinned commit>/<path>`), each checked against its pinned SHA-256
  with a size bound, assembled in a temporary folder, verified as a whole and moved into the application cache atomically.
  Only static data is fetched; nothing downloaded is executed (FogMod.exe is never fetched or run). After that the
  application works offline from the cache. DS1TR hosts nothing and ships nothing from FogMod's `dist`.
- Legal note for the project owner: the fetched event and talk files are FromSoftware-derived material that the FogMod
  repository already publishes. DS1TR does not redistribute them; the player's computer retrieves them from upstream, as the
  player would by cloning the repository. If the upstream repository is ever removed or the owner objects, the fallback is
  to refuse the world randomizer with a plain message, never to ship a copy.
