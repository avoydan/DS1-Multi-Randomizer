# Settings inventory

Generated by `node apps/desktop/scripts/settings-inventory.mjs` from the settings registry (`packages/contracts/src/settingsRegistry.ts`), the translation resources and the contracts defaults; `docs/settings-inventory.json` is the machine-readable form. Do not edit by hand: `--check` (and `src/ui/settingsCoverage.test.mjs`) fail when it is out of date.

Generation profile `ds1tr-gen-v1`. 62 options in the configuration: 59 are drawn by the interface (8 of them also in the Basic view), 3 are not drawn (see "Options that are not drawn").

The view (Basic or Advanced), the language and the help are interface state: they are not in a Seed Code, a preset or a history entry, they consume no randomness and they never change a value. Basic and Advanced are two views of one configuration; the Basic view never resets an advanced value (it says "Custom advanced settings are active." instead).

## What each option does, and when it is available

### Item randomization (`items.enabled`)

* **Mechanic:** The master switch of everything about items. When it is off, no item is moved and none of the item options do anything.
* **Affects:** Items in the world, NPC gifts, enemy drops, shops, starting classes and equipment, NPC outfits, key placement and item difficulty.
* **Limits:** It only has an effect together with at least one of the options below it. Key placement also needs "Items lying in the world".
* **Seed Code and presets:** part of the world (Seed Code, preset, history); exported and imported.
* **Evidence:** read from the code that does it.
* **Implemented in (found by search, validated in apps/backend/src/core/configValidation.ts):** `apps/backend/src/adapters/combinedRandomizerBridge.ts`, `apps/backend/src/server.ts`, `engines/combined/vendor/src/core/generator.js`.

### Items lying in the world (`items.worldItems`)

* **Mechanic:** The contents of the item pickups placed in the maps (things you pick up from the ground, from chests and from corpses) are shuffled between those places, so the item you find somewhere is usually not the one the original game puts there.
* **Affects:** Every pickup in the world except the ones the story depends on (those stay unless Key placement is on). It does not change what NPCs give, what enemies drop or what shops sell: those have their own options.
* **Limits:** Key placement, Split armor sets and the soul options need this one.
* **Example:** The Alluring Skulls that lie in the Undead Parish may turn up in the Duke's Archives instead.
* **Disabled or warned when:**
  * `itemsOff`: Turn on Item randomization to change this option.
* **Seed Code and presets:** part of the world (Seed Code, preset, history); exported and imported.
* **Evidence:** read from the code that does it.
* **Implemented in (found by search, validated in apps/backend/src/core/configValidation.ts):** `apps/backend/src/adapters/combinedRandomizerConfig.ts`, `apps/backend/src/core/configValidation.ts`, `apps/backend/src/core/generationPipeline.ts`.

### Protect progression gifts and shop goods (`items.progressionLogic`)

* **Mechanic:** While NPC gifts or Shops are shuffled, the two gifts the story depends on (the Lordvessel from Gwynevere and the Key to the Seal) are not added to the item pool, and shop goods that a story event unlocks stay where they are. A fixed list of safe goods, such as Humanity, is still shuffled.
* **Affects:** Only the NPC gifts and Shops pools.
* **Limits:** Does nothing when both NPC gifts and Shops are off. It is not what keeps keys in the world safe: that is done by the world pickup rules and by Key placement.
* **Disabled or warned when:**
  * `itemsOff`: Turn on Item randomization to change this option.
* **Seed Code and presets:** part of the world (Seed Code, preset, history); exported and imported.

### Starting weapon types (`items.startingItems`)

### Key placement (`items.keyPlacement`)

* **Mechanic:** Keys are the items the world needs to progress (for example the Basement Key, the Master Key, the Crest of Artorias and the bell keys). The modes move them to other world pickups and check the result so every area stays reachable and the Firelink Altar can be reached.
* **Affects:** The placement of key items. Item difficulty, Lordvessel placement and Lord Soul placement build on it.
* **Limits:** Needs "Items lying in the world". Race Mode + is always Fair. With the fog randomizer on, Race Mode + is made as Race Mode.
* **Choices:**
  * `vanilla` (Original): Every key stays where the game puts it.
  * `shuffled` (Shuffled): Keys move to other pickups; a safety check keeps the world completable.
  * `race` (Race Mode): Like Shuffled, but keys and embers lie only in boss rewards, chests and the places where keys normally are. Good for races.
  * `race-plus` (Race Mode +): Like Race Mode, but the world may need skips and glitches (the Capra skip, the Seal skip...); you can get stuck without them.
* **Disabled or warned when:**
  * `itemsOff`: Turn on Item randomization to change this option.
  * `warnKeysNeedWorldItems`: Key placement needs "Items lying in the world": turn it on, or the world cannot be made.
* **Seed Code and presets:** part of the world (Seed Code, preset, history); exported and imported.
* **Neutral value (an old record without the key means this):** `"vanilla"`.

### Item difficulty (`items.difficulty`)

* **Mechanic:** It only decides which of the allowed places an item prefers; it can never make a world impossible to finish. Fair puts items anywhere with equal chance. Unfair keeps desirable items out of plain view. Very Unfair hides them and rarely puts them in early areas. DS1TR rates items and places by its own rules from game data, so this approximates the original tool.
* **Affects:** Where items are placed in the pools you turned on (world, gifts, drops, shops).
* **Limits:** Race Mode + is always Fair.
* **Choices:**
  * `fair` (Fair): Items have an equal chance to be placed anywhere.
  * `unfair` (Unfair): Desirable items are not placed in plain view.
  * `very-unfair` (Very Unfair): Desirable items are hidden and rarely lie in early areas.
* **Disabled or warned when:**
  * `itemsOff`: Turn on Item randomization to change this option.
  * `racePlusFair`: Race Mode + is always Fair.
* **Seed Code and presets:** part of the world (Seed Code, preset, history); exported and imported.
